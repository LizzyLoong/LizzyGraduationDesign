# LizzyGraduationDesign
U++中为项目工程文件  
毕设开发过程中有两个分支：毕设内容分支、游戏开发分支

## 使用方法
打开项目之前需要从虚幻商城向项目中导入ParagonMinions、ParagonNarbash、Stylized_Egypt   
导入之后，应当在/Game/Content目录下看到上述三个项目的名称的文件夹   
（文件夹的名称不一定是项目的名称，但一定是上面一句话说的名称）   
然后才能打开项目   
## 目录管理
仓库一共有四个目录  
1.毕设提交与备份部分  
2.毕设内容与文档  
3.U++游戏设计部分  
4.std-cpp  

毕业论文在 /2.毕设内容与文档/Paper 中   
毕设工程在 /2.毕设内容与文档U++毕设内容部分 中。后续毕设工程可能会移动至 /3.U++游戏设计部分 并与这一部分合为一部分   
丰富游戏内容的分支在 /3.U++游戏设计部分 中，在这一部分里也有相应的开发文档、策划案和游戏资产
